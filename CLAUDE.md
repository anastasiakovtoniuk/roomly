## Технічні контракти

Перед кодом, що торкається даних, API чи помилок, звіряйся з `docs/contracts/`:

- [data_model.md](docs/contracts/data_model.md) — таблиці, поля, зв'язки, обмеження;
- [api_spec.md](docs/contracts/api_spec.md) — ендпоінти, вхідні дані, відповіді, статус-коди;
- [error_format.md](docs/contracts/error_format.md) — єдине тіло помилки й перелік кодів.

Коди помилок і HTTP-статуси бери лише з `error_format.md`; нового коду не додавай без оновлення цього файлу.
