# 6.2 Генерація автотестів з вимог

Промпти, за якими ШІ-асистенти генерували автотести з критеріїв приймання (`docs/requirements.md` §4, Gherkin) і контрактів, а не з готового коду. Кожна учасниця заповнює лише свою секцію: issue, використаний промпт, що ШІ згенерував, що довелося виправити (зайві моки, слабкі умови, закріплення помилки коду) і результат.

Порядок роботи за `docs/testing-strategy.md` (створює #47): спершу перелік тестів з ID критеріїв, потім перегляд реалізації лише для підключення. Назва тесту починається з ID критерію.
