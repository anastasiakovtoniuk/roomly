## Рахманова Вікторія

### Issue #4: Zod і спільні схеми сценарію

Помилок типів, лінтера й тестів у новому коді не було: `npm run typecheck`, `lint` і `test` (24 тести) пройшли з першого запуску.

1. **Typecheck клієнта.** Після `npm install zod@4.6.7 -w shared -w server` у клієнті впав `tsc`: не знайдено `react-router` і `@vitejs/plugin-react`. Причина: команда з `-w` установила пакети лише цих двох workspaces. Промпт: «з'ясуй причину й виправ, не змінюючи залежностей». Результат: повний `npm install`, у `package-lock.json` змінилися лише записи zod.
2. **Форматування.** `npm run format:check` знайшов три нові файли не за стилем Prettier. Промпт: «відформатуй через Prettier, логіку не змінюй». Результат: `npx prettier --write` для цих файлів, повторні перевірки зелені.

### Issue #5: автентифікація — реєстрація, вхід, вихід, сесії

Тести пройшли з першого запуску (усього 43: 24 наявні + 19 нових; після ШІ-рев'ю — 44, див. 5.3); лінтер помилок не знайшов.

1. **Typecheck тестів.** `npm run typecheck` у `server` впав: `TS2532 Object is possibly 'undefined'` у `auth.test.ts` на доступах `split(';')[0]` і `sessions[0]` (у проєкті ввімкнено `noUncheckedIndexedAccess`). Промпт: «виправ помилки типів у тесті, не послаблюючи перевірки й не додаючи `!` чи `as`». Результат: токен береться через `slice(...).split(';', 1).join('')`, а перевірка сесій порівнює масив хешів цілком (`toEqual([hash])`), що навіть суворіше за попередні два твердження.
2. **Форматування.** `npm run format:check` знайшов три нові файли не за стилем Prettier. Промпт: «відформатуй через Prettier, логіку не змінюй». Результат: `npx prettier --write` для модуля `auth/` і тесту, повторні перевірки зелені.

### Issue #6: каталог кімнат і вільні слоти

Помилок типів, лінтера й тестів не було: `npm run lint`, `typecheck`, `test` (70 тестів: 46 наявних + 24 нові), `format:check` і `build` пройшли з першого запуску. Prettier (`npx prettier --write`) асистент застосував до нових файлів до першої перевірки, логіку не змінено.
