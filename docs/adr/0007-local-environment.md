# ADR-0007. Локальне середовище й запуск

**Статус:** Запропоновано
**Дата:** 2026-10-29
**Джерела:** [requirements_digest.md](../requirements_digest.md) (TA-2, TA-12, TA-15); [3.5](../../results/3.5_acceptance_criteria_result.md) (SYS-AC-08, US-5.1, Q15); [prompts/4.2_adr_generation.md](../../prompts/4.2_adr_generation.md) («Обмеження команди»); пов'язані ADR-0001…ADR-0004.

## Контекст

- Проєкт запускається з чистого терміналу 1–2 командами з `README.md` (вимога завдання; демо на практичній зустрічі).
- Нульовий бюджет: без платного хостингу й сервісів.
- Учасники працюють на Windows і macOS **[Потребує перевірки]**.
- Камера в браузері телефона працює лише в захищеному контексті. Виняток для `localhost` діє лише на самому ноутбуці; коли телефон відкриває ноутбук за IP у локальній мережі, потрібен HTTPS. Університетська Wi-Fi може не пропускати з'єднання між пристроями **[Потребує перевірки]**.
- Пароль адміністратора береться із середовища (TA-2).

## Критерії

1. Запуск 1–2 командами на Windows і macOS без додаткових установок, крім Node.js.
2. Робочий HTTPS для камери телефона на демо без платних сервісів.
3. Мінімум налаштувань.
4. Однакове середовище для всіх 5 людей.

## Розглянуті варіанти

Запуск:

- **A. Без Docker:** Node.js LTS + npm; SQLite-файл (ADR-0004); кореневий скрипт запускає клієнт і сервер разом.
- **B. Docker Compose:** контейнери клієнта, сервера й бази.
- **C. Dev Container** (VS Code) з усіма інструментами всередині.

| Критерій | A. Без Docker | B. Docker Compose | C. Dev Container |
| --- | --- | --- | --- |
| 1–2 команди | Так | Так, але після установки Docker | Ні: відкриття через IDE |
| Установки | Лише Node.js | Docker Desktop (важкий на Windows, потребує WSL 2) | Docker Desktop + розширення |
| Налаштування | Скрипти в `package.json` | Dockerfile, compose, томи, мережа | Конфігурація контейнера |
| Однаковість | Фіксована версія Node.js і lock-файл | Найвища | Найвища |

HTTPS для телефона на демо:

- **H1. Самопідписаний сертифікат Vite** (плагін basic SSL) на IP ноутбука в локальній мережі: телефон показує попередження, після згоди камера працює.
- **H2. mkcert:** довірений локальний сертифікат; кореневий сертифікат треба встановити на кожен телефон.
- **H3. Безкоштовний тунель** (Cloudflare Quick Tunnel, без облікового запису): публічна HTTPS-адреса до локального порту клієнта; працює й тоді, коли телефон у мобільній мережі.

## Рішення

**Запуск — варіант A, без Docker** **[Пропозиція]**.

- Вимога до машини: Node.js поточної LTS-версії; версія зафіксована в репозиторії **[Пропозиція]**.
- Команда 1: `npm install` — ставить залежності всіх пакетів workspaces (ADR-0001).
- Команда 2: `npm run dev` — перед стартом створює `.env` з `.env.example`, якщо його немає, застосовує міграції, виконує ідемпотентний seed адміністратора (ADR-0004), потім паралельно запускає сервер і клієнт. Клієнт відкривається на `localhost`; запити `/api` проксуються Vite на сервер, тому клієнт і API мають одне походження (ADR-0002, ADR-0005).
- `.env.example` містить змінні без реальних секретів: пошта й пароль адміністратора для локальної розробки, порти, часовий пояс (G9). `.env` у `.gitignore`.
- На ноутбуці камера працює через `localhost` без HTTPS.

**HTTPS для демо на телефоні — H3, запасний варіант H1** **[Пропозиція]**.

- Основний: окремий скрипт демо запускає безкоштовний тунель до порту клієнта; телефон відкриває отриману HTTPS-адресу. Завдяки проксі `/api` достатньо одного тунелю. Сервер розробки має дозволити хост тунелю. Потрібна утиліта тунелю й інтернет; доступність без облікового запису перевірити до демо **[Потребує перевірки]**. Через тунель ідуть лише тестові дані.
- Запасний: скрипт запуску з самопідписаним сертифікатом на IP ноутбука, якщо тунель недоступний, а телефон і ноутбук в одній мережі.
- Перед демо прогнати сценарій сканування на iOS і Android (ADR-0008).

## Наслідки

- Простіше: жодної установки бази чи Docker; той самий запуск у всіх.
- Складніше: Node.js має бути встановлений; Windows-специфіку шляхів і скриптів треба перевірити (скрипти пишуться кросплатформено).
- Прийнятий ризик: тунель — зовнішній безкоштовний сервіс без гарантій; є запасний варіант. Самопідписаний сертифікат показує попередження браузера.
- Для 4.4: `README.md` описує дві команди, вимогу до Node.js, скрипт демо з HTTPS і де взяти пароль адміністратора.
- Стосується: Олександри (скрипти, README), усіх (перевірка запуску на своїй ОС у перший тиждень).

## Що відхилено

- **B. Docker Compose** — Docker Desktop на кожній машині й налаштування контейнерів без потреби, бо база — файл SQLite.
- **C. Dev Container** — прив'язка до IDE й Docker, запуск не 1–2 командами з терміналу.
- **H2. mkcert** — встановлення кореневого сертифіката на кожен телефон, особливо на iOS, займає більше часу, ніж дає.
