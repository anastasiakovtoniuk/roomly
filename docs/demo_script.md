Живе демо на початку практичної зустрічі: **3–4 хвилини**, далі обговорення. Присутність усієї команди обов'язкова. Сценарій показує новий обсяг ([checkin_admin_flow.md](scenarios/checkin_admin_flow.md)), автотести й один знайдений баг ([testing-report.md](testing-report.md) §3).

## Підготовка (за 20–30 хв до зустрічі)

1. Чистий клон `main`: `git clone https://github.com/anastasiakovtoniuk/roomly.git`, `npm install`, `npm run dev`, у другому терміналі — `npm run db:seed:demo -w server`. Перевірити дату й час ноутбука ([README](../README.md), «Обмеження MVP щодо "сьогодні"»).
2. Два вікна браузера: звичайне під адміністратором (`ADMIN_EMAIL` / `ADMIN_PASSWORD` з `.env`) і приватне під студентом (зареєструвати заздалегідь).
3. **Бронювання для автоскасування.** Щонайменше за 20 хв до демо адміністратор створює слот кімнати A, що починається за 2–3 хв; студент бронює його й **не** підтверджує. Через 15 хв після початку (гіпотеза H01) сервер переведе бронювання в «Автоскасоване» (таймер кожні 30 с, рішення 9).
4. **Бронювання для check-in.** Слот кімнати B має початися за 1–2 хв до демо, щоб на демо вже йшло вікно підтвердження. Студент бронює його заздалегідь. Кінець слота — щонайменше через 20 хв.
5. QR кімнати B: адміністратор → «Адмін: кімнати» → «QR-код для друку» → «Друкувати» → «Зберегти як PDF». PDF відкрити на телефоні (або роздрукувати), щоб показати вебкамері ноутбука.
6. Термінал у корені клону з уже набраною командою `npm test`; у редакторі відкрити `server/test/checkIns.ac.test.ts` на тесті `US-5.1-AC-01 (S02)`.

## Резервний план

| Що зламалося | Що робимо |
| --- | --- |
| Вебкамера не вмикається або не читає QR | Збільшити яскравість телефона, піднести ближче. Інакше — скріншоти успішного скану й статусу «Підтверджене», зняті на репетиції. Ручне введення коду на екрані check-in («Немає камери?») для демо не підходить: адмін-екран не показує токен текстом (FB-12) |
| Бронювання кімнати A ще не автоскасоване | Показати відлік «Час підтвердження минув, оновлюємо статус…» і пояснити: сервер змінить статус до 30 с; паралельно — скріншот з репетиції |
| Слот кімнати B уже завершився або не почався | Показати «Ще зарано» / «Немає поточного бронювання» як очікувані відповіді й перейти до скріншотів |
| Не стартує `npm run dev` | Друге вікно з уже запущеним застосунком на ноутбуці іншої учасниці; інакше — запис екрана з репетиції |
| `npm test` довгий або червоний | Показати збережений вивід із репетиції й `docs/testing-report.md` §5; червоний результат не приховуємо, а пояснюємо |

Мережа для демо не потрібна: застосунок працює на `localhost`. HTTPS-тунель (`npm run dev:tunnel`) потрібен лише для камери телефона й у демо не використовується.
